 - RBA (role based Access / Authorization)
 - panels / dashboads (admin,employees)
  ---
## Functionality and Core Features
> admin
 - admin can create/add new employee 
 - admin can grant access to employee
 - admin can assign tasks to employee
 - admin can manage and analyse the employee details 
 - stats for task management 

> employee
 - employee can login 
 - employee can view assigned task and manage tasks
 - employee can close task by updating message and status
 - employee can manage profile details 
 - employee can skip task with a reason
